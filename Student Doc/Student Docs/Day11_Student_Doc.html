PART 1 — FOLLOW ALONG WITH YOUR INSTRUCTOR
Topic 1 addEventListener element + event name + handler fn
Pattern:   element.addEventListener("eventName", fn)
Multiple listeners allowed. Cleanly removable with named handlers. 
const btn = document.querySelector("#my-btn");

btn.addEventListener("click", () => {
  console.log("Button clicked!");
});

// You can attach multiple listeners — all run
btn.addEventListener("click", () => {
  console.log("Second handler also fires");
});

// To remove a listener, you need a NAMED handler — not an arrow inline
function handleClick() {
  console.log("Handled");
}

btn.addEventListener("click", handleClick);
btn.removeEventListener("click", handleClick);
Topic 2 The Event Object e.target · e.key · e.target.value

VISUAL REFERENCE

Property What it is
e.type The event name ("click")
e.target The element it happened on
e.target.value Input's current value
e.target.textContent Element's text
e.key Which key (keyboard)
e.clientX / clientY Mouse coordinates 
const btn = document.querySelector("#my-btn");

btn.addEventListener("click", (e) => {
  console.log(e.type);            // "click"
  console.log(e.target);          // the <button> element
  console.log(e.target.textContent);   // its text
  console.log(e.clientX, e.clientY);   // mouse coordinates
});

// Input — e.target.value is what the user typed
const input = document.querySelector("#name-input");
input.addEventListener("input", (e) => {
  console.log("User typed:", e.target.value);
});

// Keyboard — e.key is which key
document.addEventListener("keydown", (e) => {
  console.log("Pressed:", e.key);   // "a", "Enter", "ArrowUp"
});

Topic 3 preventDefault & stopPropagation Override default behaviour
Some elements have built-in defaults:
• Forms submit and reload the page.
• Links navigate.
• Right-click opens browser menu.
e.preventDefault() cancels them. 
const form = document.querySelector("#login-form");

form.addEventListener("submit", (e) => {
  e.preventDefault();     // stop the page reload
  console.log("Custom form handling here");
  // ... validate, send via fetch, etc.
});

// Links
const link = document.querySelector("a");
link.addEventListener("click", (e) => {
  e.preventDefault();     // don't navigate
  console.log("Intercepted");
});

// Right-click — disable browser menu (rarely good UX, but you can)
document.addEventListener("contextmenu", (e) => {
  e.preventDefault();
});
Topic 4 Mouse Events click · dblclick · mouseover · contextmenu
Event Fires on
click Single click
dblclick Double click
mouseover Pointer enters
mouseout Pointer leaves
contextmenu Right click 
const box = document.querySelector("#box");

box.addEventListener("click",        () => console.log("click"));
box.addEventListener("dblclick",     () => console.log("double click"));
box.addEventListener("mouseover",    () => box.classList.add("hover"));
box.addEventListener("mouseout",     () => box.classList.remove("hover"));
box.addEventListener("contextmenu",  (e) => {
  e.preventDefault();
  console.log("right-clicked at", e.clientX, e.clientY);
});
Topic 5 Keyboard Events keydown · keyup · input
Event Use for
input "As you type" — current value
keydown "Which key was pressed" — Enter, Escape, Ctrl+S
keyup After release 
const input = document.querySelector("#search");

// LIVE — best for "as you type" updates
input.addEventListener("input", (e) => {
  console.log("Value now:", e.target.value);
});

// Specific keys
input.addEventListener("keydown", (e) => {
  if (e.key === "Enter") {
    console.log("Search:", e.target.value);
  }
  if (e.key === "Escape") {
    e.target.value = "";
  }
});

// Modifier keys
document.addEventListener("keydown", (e) => {
  if (e.ctrlKey && e.key === "s") {
    e.preventDefault();   // override browser save
    console.log("Custom save");
  }
});
⚠️ keydown shows the OLD value — at the moment keydown fires, the input hasn't updated yet. Use input for the current value.
Topic 6 Bubbling & Event Delegation One listener, many elements
Bubbling:   Events fire on the target, then bubble UP through ancestors.
Delegation:   Attach ONE listener to a parent. Use e.target to know which child.
Bonus:   Works for elements added LATER. 
<ul id="todo-list">
  <li data-id="1">Buy milk</li>
  <li data-id="2">Walk dog</li>
  <li data-id="3">Pay bills</li>
</ul>

// WITHOUT delegation — one listener per item, repeated work
document.querySelectorAll("#todo-list li").forEach(li => {
  li.addEventListener("click", () => {
    li.classList.toggle("done");
  });
});

// WITH delegation — ONE listener on the parent
const list = document.querySelector("#todo-list");

list.addEventListener("click", (e) => {
  // Was the click on an <li>?
  if (e.target.tagName === "LI") {
    e.target.classList.toggle("done");
    console.log("Toggled item", e.target.dataset.id);
  }
});

// Now even items added LATER work — no extra wiring
const newLi = document.createElement("li");
newLi.textContent = "Brand new task";
newLi.dataset.id = "4";
list.appendChild(newLi);    // clicking it just works

PART 3 — VISUAL SUMMARY

Listener Pattern

Step Code
Attach el.addEventListener("click", fn)
Remove el.removeEventListener("click", fn)
Inline (avoid) el.onclick = fn

Event Object

Property Use
e.target Element fired on
e.target.value Input value
e.key Pressed key
e.preventDefault() Cancel default
e.stopPropagation() Stop bubble

Mouse vs Keyboard

Mouse Keyboard
click / dblclick keydown / keyup
mouseover / mouseout input
contextmenu (right) (modifier keys: e.ctrlKey)

Delegation Pattern

Step Action
1 Attach ONE listener to parent
2 Read e.target
3 Filter: if (e.target.tagName === "LI")
✓ Works for future items too
