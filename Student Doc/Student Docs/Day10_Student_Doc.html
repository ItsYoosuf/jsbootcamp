Topic 1 What is the DOM? Document Object Model
The browser parses your HTML and builds a tree of objects in memory. That tree is the DOM.
JS reads and modifies that tree → browser re-renders. Root: document. 
document
  └── html
       └── body
            ├── h1#title
            └── button.btn
Topic 2 Selecting Elements getElementById · querySelector · querySelectorAll

VISUAL REFERENCE

Method Returns
document.getElementById("x") One element or null
document.querySelector("#x") First match or null
document.querySelector(".btn") First match by class
document.querySelector("nav a") First nested match
document.querySelectorAll(".btn") NodeList of all
Default to querySelector — it accepts any CSS selector.
⚠️ querySelectorAll is NOT an array. It's a NodeList. forEach works, but map/filter don't.
Convert:   [...document.querySelectorAll(".btn")] 
// By ID — fast, returns ONE element or null
const title = document.getElementById("title");

// By class — returns a live HTMLCollection (array-like)
const buttons = document.getElementsByClassName("btn");

// MODERN — querySelector uses CSS selectors
// Returns the FIRST match, or null
const heading = document.querySelector("h1");
const firstBtn = document.querySelector(".btn");
const idMatch  = document.querySelector("#title");
const nested   = document.querySelector("nav a.active");

// querySelectorAll — returns ALL matches as a NodeList
const allBtns = document.querySelectorAll(".btn");
allBtns.forEach(b => console.log(b.textContent));
Topic 3 textContent vs innerHTML Text vs HTML — and security
textContent — plain text. Tags inside are shown as raw characters. Safe.
innerHTML — HTML. Tags become real tags. NEVER with user input — XSS attack vector. 
const title = document.querySelector("#title");

// Read
console.log(title.textContent);    // "Hello"
console.log(title.innerHTML);      // "Hello"

// Write — text
title.textContent = "Welcome, Priya!";

// Write — HTML
title.innerHTML = "Welcome, <em>Priya</em>!";

// DANGER — never do this with user input
const userInput = "<img src=x onerror=alert('hacked')>";
title.innerHTML = userInput;       // ⚠️ XSS attack vector
title.textContent = userInput;     // ✅ safe, shows as raw text

Topic 4 Modifying Styles · classList Inline style vs CSS classes
const title = document.querySelector("#title");

// Direct style — quick and dirty
title.style.color = "red";
title.style.backgroundColor = "yellow";   // camelCase, not "background-color"
title.style.fontSize = "32px";

// classList — preferred
title.classList.add("highlight");
title.classList.remove("dim");
title.classList.toggle("active");          // adds if missing, removes if present
console.log(title.classList.contains("active"));   // true / false
Default to classList. Define styles in CSS, flip classes from JS.
Topic 5 Creating Elements 3 steps: create · configure · insert
// 1. Create
const li = document.createElement("li");

// 2. Configure
li.textContent = "Buy milk";
li.classList.add("todo-item");
li.id = "todo-1";

// 3. Insert
const list = document.querySelector("#todo-list");
list.appendChild(li);     // adds to END

// Other inserts
list.prepend(li);         // adds to START
list.append(li1, li2);    // multiple at end
Element doesn't exist on the page until you insert it.
Topic 6 Removing Elements .remove() and emptying
// Remove an element from its parent — clean
const li = document.querySelector("#todo-1");
li.remove();

// Remove all children
const list = document.querySelector("#todo-list");
list.innerHTML = "";       // quick way, not always recommended
