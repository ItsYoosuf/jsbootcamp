Topic 1 The Classic for Loop init ; condition ; update

VISUAL REFERENCE

Syntax:   for (init; condition; update) { ...body }
Order:   init runs once → check condition → run body → update → check condition → repeat.
Part Example When
init let i = 0 Once at start
condition i < 5 Before each iteration
update i++ After each iteration

Topic 2 while & do...while When you don't know the count upfront

VISUAL REFERENCE

while (cond) { ... } — checks condition FIRST, then runs body. May never run.
do { ... } while (cond); — runs body FIRST, then checks. Always runs at least once.
⚠️ Critical: Something inside the loop must make the condition false eventually — otherwise infinite loop!

FOLLOW ALONG

let i = 0;
while (i < 3) { console.log(i); i++; }
→
your answer
let n = 10;
do { console.log(n); n++; } while (n < 5);
→
your answer
Topic 3 break & continue Fine control inside any loop

VISUAL REFERENCE

break — exits the loop ENTIRELY, immediately. No more iterations.
continue — skips the REST of the current iteration and jumps to the next one. Loop keeps going.

FOLLOW ALONG

for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i);
}
→
your answer
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i);
}
→
your answer
Topic 4 for...of — Arrays & Strings Modern, clean iteration over values
Syntax:   for (const value of iterable) { ...body }
Works on: arrays, strings, Maps, Sets — any iterable.
Use const in the head — the variable is freshly declared each iteration, never reassigned.

FOLLOW ALONG

const fruits = ["apple", "banana", "mango"];
for (const f of fruits) console.log(f);
→
your answer
for (const ch of "Priya") console.log(ch);
→
your answer
Topic 5 for...in — Object Keys Walk through every property of an object
Syntax:   for (const key in object) { ...body }
Gives you the KEY (property name). Use obj[key] to get the value.
⚠️ Don't use for...in on arrays! Keys come back as strings, and it can pick up extra properties. Always use for...of for arrays.
Memory aid:   In for keys (think index),   Of for values.

FOLLOW ALONG

const s = { name: "Aarav", age: 22 };
for (const k in s) console.log(k);
→
your answer
for (const k in s) console.log(k, s[k]);
→
your answer
Topic 6 Avoiding Infinite Loops The most painful beginner mistake
The 3 classic ways to freeze your browser:
1. Forgetting to update the counter (i++ missing)
2. Updating in the wrong direction (i-- when you needed i++)
3. Condition that can never be false (while (true))
If your tab freezes: just close it. Don't try to fix it from inside. This will happen to you at least once — it's a rite of passage. 
// Spot the bug — why is this infinite?
let i = 0;
while (i < 5) {
  console.log(i);
  // ???
}

PART 3 — VISUAL SUMMARY

Loop Types at a Glance

Loop Best for Example
for Known count for (let i = 0; i < 10; i++)
while Unknown count, condition-driven while (input !== "quit")
do...while Must run at least once Validating user input
for...of Array / string values for (const x of arr)
for...in Object keys for (const k in obj)

break vs continue

Keyword Effect
break Exits the loop entirely
continue Skips this iteration, runs next

for...of vs for...in

Use Loop
Array values for...of
String characters for...of
Object keys for...in
Array indices classic for (let i = 0; ...)

Memory aid: In for keys, Of for values.

Infinite Loop Checklist

Check Example
Counter updated? Don't forget i++
Right direction? Don't write i-- when you mean i++
Can condition be false? Avoid bare while (true)
