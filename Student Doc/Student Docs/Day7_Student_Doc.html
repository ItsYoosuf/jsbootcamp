Topic 2 Mutating Methods Change the original

VISUAL REFERENCE

Method Action
push(item) Add to END
pop() Remove from END
unshift(item) Add to START
shift() Remove from START
splice(i, n) Remove n items at i
splice(i, 0, x) Insert x at i
"p" methods work at the END (push, pop). "shift" methods work at the START. 
const cart = ["apple", "banana"];

cart.push("mango");        // ["apple", "banana", "mango"]
cart.pop();                // ["apple", "banana"], returns "mango"
cart.unshift("orange");    // ["orange", "apple", "banana"]
cart.shift();              // ["apple", "banana"], returns "orange"

// splice(start, deleteCount, ...itemsToInsert)
const items = ["a", "b", "c", "d"];
items.splice(1, 2);        // remove 2 items starting at index 1
console.log(items);        // ["a", "d"]

const more = ["a", "b", "c"];
more.splice(1, 0, "X", "Y");   // insert at 1, delete 0
console.log(more);             // ["a", "X", "Y", "b", "c"]
Topic 3 Non-Mutating Methods Return new — original safe
Method Returns
slice(s, e) New array, partial copy
concat(arr2) New combined array
join("-") A STRING
includes(x) true / false
indexOf(x) Index or -1
⚠️ slice vs splice — one letter, opposite worlds.
slice = safe copy.    splice = mutates. 
const arr = [1, 2, 3, 4, 5];

console.log(arr.slice(1, 3));      // [2, 3]   ← new array, original untouched
console.log(arr.concat([6, 7]));   // [1, 2, 3, 4, 5, 6, 7]
console.log(arr.join("-"));        // "1-2-3-4-5"   ← string!
console.log(arr.includes(3));      // true
console.log(arr.indexOf(4));       // 3 (index)
console.log(arr);                  // [1, 2, 3, 4, 5]   ← original same
Topic 4 forEach & map Run a function on each element
forEach(fn) — runs fn on each element. Returns undefined. Use for side effects.
map(fn) — runs fn on each element AND returns a NEW array. Use to transform. 
const numbers = [1, 2, 3, 4];

// forEach — side effect, no return
numbers.forEach(n => console.log(n * 2));
// 2, 4, 6, 8 (printed)

// map — transform, returns new array
const doubled = numbers.map(n => n * 2);
console.log(doubled);      // [2, 4, 6, 8]
console.log(numbers);      // [1, 2, 3, 4]   ← original untouched

// Real example — add 18% GST
const prices = [100, 200, 300];
const withGst = prices.map(p => p * 1.18);
console.log(withGst);      // [118, 236, 354]

Topic 5 filter · find · some · every Predicates: fn returning true/false
Method Returns
filter(fn) NEW array of all that pass
find(fn) FIRST match (or undefined)
some(fn) true if AT LEAST ONE passes
every(fn) true if ALL pass 
const scores = [88, 42, 75, 60, 91, 39];

// filter — keep only passing scores
const passing = scores.filter(s => s >= 60);
console.log(passing);                      // [88, 75, 60, 91]

// find — first failing score
const firstFail = scores.find(s => s < 60);
console.log(firstFail);                    // 42

// some — any failures?
console.log(scores.some(s => s < 60));     // true

// every — all passing?
console.log(scores.every(s => s >= 60));   // false

Topic 6 reduce — Aggregation Fold a list into one value
Syntax:   arr.reduce((acc, current) => ..., startingValue)
The function runs once per element. The accumulator carries forward. 
const numbers = [1, 2, 3, 4, 5];

// Sum
const total = numbers.reduce((acc, n) => acc + n, 0);
console.log(total);   // 15

// Step by step:
// start: acc = 0
// 1st:   acc = 0 + 1 = 1
// 2nd:   acc = 1 + 2 = 3
// 3rd:   acc = 3 + 3 = 6
// 4th:   acc = 6 + 4 = 10
// 5th:   acc = 10 + 5 = 15

// Max value
const max = numbers.reduce((a, n) => n > a ? n : a, -Infinity);
console.log(max);     // 5

Topic 7 Spread Operator ...arr expands array into elements
Three uses:
1. Copy:   [...a]
2. Merge:   [...a, ...b]
3. Pass as args:   Math.max(...nums) 
const a = [1, 2, 3];
const b = [4, 5, 6];

// Copy
const aCopy = [...a];
console.log(aCopy);          // [1, 2, 3]

// Merge
const merged = [...a, ...b];
console.log(merged);         // [1, 2, 3, 4, 5, 6]

// Insert in the middle
const sandwiched = [...a, 99, ...b];
console.log(sandwiched);     // [1, 2, 3, 99, 4, 5, 6]

// Pass as arguments
console.log(Math.max(...a));   // 3
