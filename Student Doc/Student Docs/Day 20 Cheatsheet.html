Event Loop Algorithm

Step Action
1 Stack empty? Wait
2 Drain ALL microtasks
3 Take ONE macrotask
4 Repeat
Microtasks ALWAYS drain before any macrotask.

The Classic Puzzle

console.log("1");
setTimeout(
  () => console.log("2"), 0
);
Promise.resolve().then(
  () => console.log("3")
);
console.log("4");

// Output: 1, 4, 3, 2
//
// 1, 4 → sync
// 3    → microtask (drains first)
// 2    → macrotask (last)

Why setTimeout(0) ≠ "Now"

⚠️ "0ms" means: as soon as possible, AFTER sync + ALL microtasks.

Don't Block

// BAD — freezes everything
function block(ms) {
  const t0 = Date.now();
  while (Date.now() - t0 < ms) {}
}

// GOOD — chunk work
function chunked(items, fn, n=100) {
  let i = 0;
  function tick() {
    const end = Math.min(i + n, items.length);
    while (i < end) fn(items[i++]);
    if (i < items.length) {
      setTimeout(tick, 0);  // yield
    }
  }
  tick();
}

await is a Microtask

async function f() {
  console.log("a");
  await null;          // yields here
  console.log("b");    // microtask continuation
}

f();
console.log("c");
// Output: a, c, b

Q & A — Common Questions

Q1: What does the loop do?
Forever: when stack is empty, drain ALL microtasks, then take ONE macrotask, run it, repeat.
Q2: Microtask vs Macrotask?
Micro: Promise, queueMicrotask, MutationObserver. Macro: setTimeout, setInterval, I/O, UI events. Micro has priority — all drain before any macro.
Q3: Why setTimeout(0) last?
Timer callbacks go to the macrotask Q, only processed when stack is empty AND all microtasks have drained.
Q4: Truly single-threaded?
YOUR JS code runs on one thread. The runtime around it is multi-threaded under the hood. Web Workers give extra JS threads but no shared memory.
Q5: Are setTimeout / fetch part of JS?
No — host APIs provided by browser/Node, not the language spec. The spec only covers engine: parser, stack, heap, microtask Q.
Q6: What's microtask starvation?
When microtasks keep scheduling more microtasks, the macrotask Q never gets a turn. Timers and UI freeze. Avoid recursive microtask scheduling.
Q7: Where does async/await fit?
await is a microtask — the function continuation queues as a microtask when the awaited Promise resolves. Same ordering as .then.
